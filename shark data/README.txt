ABSTRACT: 
This dataset is associated to the article “An ecological assessment of large coastal shark communities in South Florida” by Tinari and Hammerschlag (2021), published in Ocean and Coastal Management, https://doi.org/10.1016/j.ocecoaman.2021.105772. Specifically, these are the data used to create figures 1, 2, 3, and 4 and tables 1, 2, 3, 4, and 5. These data are the results of standardized drumline surveys from Miami through the middle Florida Keys to examine spatial, seasonal, and environmental patterns in shark occurrence, catch per unit effort, composition, and demographic structure. Between 2009 and 2021, a total of 21,755 drumlines were deployed, capturing 3,398 sharks, comprising fifteen species. Ginglymostoma cirratum, (n=1335), Carcharhinus limbatus, (n=650), Negaprion brevirostris, (n=314), C. leucas, (n=253), and Sphyrna mokarran, (n=238) were the most common species encountered. At the assemblage level, relative abundance among regions and seasons were generally similar; however clear species-specific patterns of abundance, size structure, and sex-composition were detected by season, region, habitat, and management zones. These data serve as a baseline for future monitoring of shark populations in South Florida and assessing their response to environmental change. Mark recapture sharks were also analyzed to provide insights into the distances traveled and time at liberty.

COMMENTS:
This dataset contains 3 .csv files that serve as the basis for the analyses conducted in Tinari and Hammerschlag (2021, DOI:10.1016/j.ocecoaman.2021.105772).

DESCRIPTION:
The zip file contains:
• SharksBySet.csv (Main file used for all coded analysis - This is a summary of the number of sharks caught per set of 5 drumlines)
	* This file contains a table with the the results of the standardized drumline surveys reported in this study. 
	* Each row in the table represents a set of 5 drumlines (hereafter, just "set").
	* Each set is assigned a unique sample number identified by the column header 'Sample'.
	* In the table, the following corresponding information specific to each set is provided: Season, Region, Habitat, ManagementZone, Latitude, Longtitude, Temperature, DissolvedOxygen, Salinity, MaximumDepth, and the columns with the number of individuals of each shark species captured in the set (Nurse, Blacknose, AtlanticSharpnose, Blacktip, Bull, GreatHammerhead, Lemon, Sandbar, Tiger, GreatWhite, Bonnethead, CaribbeanReef, Dusky, ScallopedHammerhead, and Spinner).
	* This file contains all the data corresponding with figures 1, 2, 3 and tables 1, 3, and 4 of the study paper.
• OriginalAndRecaptureLocations.csv 
	* This file contains all the data corresponding with the mark-recapture events reported in Figure 4 and Table 5 of the study paper.
	* Note that distances traveled and dispersion rates are based on straight line distances between mark and recapture points that avoid land.
	* DisplacementCategory defines the location of Figure 4 each mark-recapture event is in. Long corresponds to Figure 4a, Medium corresponds to Figure 4b and Short corresponds to Figure 4c.
	* Original in the Original/Recap column denotes original capture event. Recap1 is the first time the individual was recaptured. Recap2 is the second time the individual was recaptured. E in Original/Recap column denotes location selected to avoid calculating distance over land. 
	* DaysAtLiberty is the number of days between first and last capture events.
	* TrackLength is the straight line distance avoiding land between capture events.
• TotalLengthandSex.csv 
	* This file contains the corresponding demographic information for sharks surveyed in the study.
	* The total length (TL) in cm and the sex for each shark surveyed is provided in the table.
	* The table also includes the following corresponding information for each shark: the set from which it was sampled, denoted by the column labeled Sample, Latitude, Longitude, Season, Habitat, ManagementZone, and Region.
	* This file contains all the data corresponding with table 2 of the study paper.
        

NOTE: any information missing is these datasets are denoted with a "NA" in the table cell.
